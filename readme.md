# koishi-plugin-pictime

[![npm](https://img.shields.io/npm/v/koishi-plugin-pictime?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-pictime)

图图时间！

本插件基于[pictures-time](https://github.com/Alin-sky/koishi-plugin-pictures-time)插件。

## 📸 用法介绍

本插件用于记录群聊中用户发送的图片数量，并提供排行榜功能。其特色在于支持在一个记录会话中连续发送多张图片并进行保存和计数。

### 1. 开始记录 ⏱️

*   在群聊中发送指令：
    ```
    pictime
    ```
    或者别名：
    ```
    图图time
    ```
*   机器人会提示你开始记录。

### 2. 发送图片 🖼️

*   在机器人提示开始后，发送你想要记录的图片（**支持连续发送多张**）。
*   插件会自动处理你发送的图片消息，提取图片并准备保存。

### 3. 结束记录 ✅

*   当你发送完所有想记录的图片后，发送指令：
    ```
    over
    ```
    或者别名：
    ```
    停止
    ```
*   机器人会停止监听你的图片消息，并回复本次会话成功保存的图片数量、出错数量以及你累计在本插件中记录的总图片数量。

### 4. 查看排行 🏆

*   在群聊中发送指令：
    ```
    pictime.rankings
    ```
    或者别名：
    ```
    图图排行
    ```
*   机器人会显示**当前群聊**中，累计发图数量最多的前 10 名用户。

### 5. 配置项 ⚙️

你可以在 Koishi 控制台的插件配置界面找到本插件的设置：

*   **`paths`**: 设置图片存储的根目录。默认为 `image-time`，这是一个相对于 Koishi 数据目录 (`data/`) 的路径。可以更改为绝对路径。

### 重要提示 ✨

*   只有**执行 `pictime` 指令的用户本人**发送的图片才会被该次会话记录。其他用户在同一时间发送的图片不会被计入你的当前会话。
*   每个用户的记录会话是独立的。
*   图片下载和保存依赖网络和文件系统权限，请确保 Koishi 具有相应的访问权限。
